# 🎓 Student Management System

A simple and efficient **Student Management System** built to manage student records digitally. This project allows users to add, update, delete, and view student information in an organized manner.

## 🚀 Features

- ➕ Add new student records
- 📝 Update existing student details
- ❌ Delete student records
- 🔍 Search students by ID or name
- 📋 View all student records
- 💾 Store and manage data efficiently
- 📱 User-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- database MySQL
- backend technology PHP

## 🎯 Purpose

The main goal of this project is to simplify the process of managing student information and reduce manual record-keeping. It provides an easy way to maintain and access student data.
